# **App Name**: SignaGenius

## Core Features:

- Signature Design Generation: Generates signature designs based on user input (name, style preferences). AI Tool for assessing aesthetic qualities.
- Style Customization: Allows users to customize various aspects of the signature, such as font, slant, weight, and flourishes.
- Preview and Download: Lets users preview their signature design and download it in various formats (SVG, PNG, etc.).
- Style Trend Analysis: AI analyzes the entered signature, providing real-time suggestions of elements of styles trending in 2025. Can adapt based on selected website review from prompt.

## Style Guidelines:

- Primary color: Deep indigo (#3F51B5) evoking professionalism and sophistication.
- Background color: Light grayish-blue (#ECEFF1) to provide a clean and modern feel.
- Accent color: Vibrant coral (#FF7043) for call-to-action buttons and interactive elements.
- Headline font: 'Playfair', serif, for titles. Note: currently only Google Fonts are supported.
- Body font: 'PT Sans', sans-serif, for the body. Note: currently only Google Fonts are supported.
- Use a set of minimalist icons, and keep the style consistent.
- Implement a clean, card-based layout for signature options.
